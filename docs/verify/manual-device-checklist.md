# 真机人工验证清单

> 适用：模拟器无相机、系统 UI 无法自动化，或需要杀进程/系统分享面板的场景。
> 本清单只提供步骤与回填表格，**不预填结论**。执行后请复制为 `docs/verify/manual-device-<YYYYMMDD>.md` 填写，并在 `docs/traceability.md` 对应 Txx 追加证据链接。
> 前置：真机已安装 Debug 构建（Xcode 直接运行或 `xcrun devicectl device install app`），系统版本记入下表。

## 1. T03 相机权限允许

1. 若此前已授权，先在「设置 → BizScan」关闭相机权限并删除 App 重装。
2. 打开 App → 点「扫描」。
3. 系统弹窗选择「允许」。

预期：进入取景页，画面为实时相机预览，底部有快门与「导入照片」，左上有关闭按钮。

## 2. T03 相机权限拒绝

1. 「设置 → BizScan → 相机」关闭。
2. 回到 App → 点「扫描」。

预期：显示「需要相机权限」页，含「打开设置」与「返回」两个按钮；点「打开设置」能跳到本 App 设置页；点「返回」回到名片夹。

## 3. T04 拍摄 → 进入边界校正

1. 将一张名片平放在纯色桌面，尽量填满取景框的虚线区域。
2. 点快门。

预期：1–3 秒内进入「调整名片边界」页；自动四边形贴合名片边缘（底部显示置信度）；点「下一步」进入校正页。

## 4. T05 相册导入 → 进入边界校正

1. 相册中预置一张名片照片。
2. 扫描页点「导入照片」→ 选择该图。

预期：同样进入「调整名片边界」页，且图片为所选照片。

## 5. T06 倾斜名片自动检测

1. 将名片以约 10°–20° 倾斜放置，背景与名片颜色有明显对比。
2. 拍摄后观察自动四边形。

预期：四点贴合名片四角，无明显外扩或内缩；记录底部显示的置信度数值。

## 6. T20 校正页重拍与 90° 旋转

1. 在「调整名片边界」页点「取消」。

预期：回到扫描页，可继续拍摄（即「重拍」路径）。

2. 再次拍摄 → 点右上角旋转按钮一次。

预期：出现「输出将旋转 90°」提示；点「下一步」后，校正页中的图像方向已旋转 90°（竖版名片变为横版可读）。

## 7. T18 杀进程后数据保持

1. 完成一张名片的保存，并添加一个标签、填写备注。
2. 从多任务界面上滑杀掉 App。
3. 冷启动 App，打开该名片。

预期：姓名/公司/职位/电话/邮箱/地址/标签/备注与原图全部保留；列表顺序按最近更新排列。

## 8. T19 系统分享面板导出 vCard

1. 打开任意名片 → 点「分享」。
2. 在系统分享面板选择「存储到文件」。

预期：面板中文件名为 `.vcf`；保存后用「文件」App 打开，内容以 `BEGIN:VCARD` 开头并含 `FN:` / `TEL;TYPE=CELL:` 等行。
