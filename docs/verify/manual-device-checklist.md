# 真机验收程序（可转移）

> **本文件的性质**：这是一份**待外部执行的验收程序**，不是未完成的工作项。本项目自始至终没有 iOS 真机，因此下列条目不产生任何结论；它们以 B 类的形式记录在 [`../acceptance-report.md`](../acceptance-report.md) 与 [`../verification-debt.md`](../verification-debt.md)。
> 适用：模拟器无相机、系统 UI 无法自动化，或需要杀进程/系统分享面板的场景。
> 执行后请复制为 `docs/verify/manual-device-<YYYYMMDD>.md` 填写，并在 `docs/traceability.md` 对应 Txx 把类别由 B 改为 A。
> 前置：真机已安装 Debug 构建（Xcode 直接运行或 `xcrun devicectl device install app`），系统版本记入下表。

## 0.1 执行约定

- **不预填结论**：本文件中的"预期"是判定标准，不是已完成的事实；未执行前结果列保持空白。
- **证据命名**：`T<编号>-<结果>-<序号>.<扩展名>`，例如 `T03-allow-01.mov`、`T31-success-01.png`；FAIL 必须附截图或录屏。
- **判定方法**：每条以"预期"为唯一标准；观察到偏差时如实记 FAIL，并同步在 `../verification-debt.md` 登记为执行失败。
- **环境记录**：设备型号、系统版本、构建号必填，否则该条不计入 A 类。

## 1. T03 相机权限允许

1. 若此前已授权，先在「设置 → BizScan」关闭相机权限并删除 App 重装。
2. 打开 App → 点「扫描」。
3. 系统弹窗选择「允许」。

预期：进入取景页，画面为实时相机预览，底部有快门与「导入照片」，左上有关闭按钮。

## 2. T03 相机权限拒绝

1. 「设置 → BizScan → 相机」关闭。
2. 回到 App → 点「扫描」。

预期：显示「需要相机权限」页，含「打开设置」与「返回」两个按钮；点「打开设置」能跳到本 App 设置页；点「返回」回到名片夹。

## 3. T04 拍摄 → 进入边界校正

1. 将一张名片平放在纯色桌面，尽量填满取景框的虚线区域。
2. 点快门。

预期：1–3 秒内进入「调整名片边界」页；自动四边形贴合名片边缘（底部显示置信度）；点「下一步」进入校正页。

## 4. T05 相册导入 → 进入边界校正

1. 相册中预置一张名片照片。
2. 扫描页点「导入照片」→ 选择该图。

预期：同样进入「调整名片边界」页，且图片为所选照片。

## 5. T06 倾斜名片自动检测

1. 将名片以约 10°–20° 倾斜放置，背景与名片颜色有明显对比。
2. 拍摄后观察自动四边形。

预期：四点贴合名片四角，无明显外扩或内缩；记录底部显示的置信度数值。

## 6. T20 校正页重拍与 90° 旋转

1. 在「调整名片边界」页点「取消」。

预期：回到扫描页，可继续拍摄（即「重拍」路径）。

2. 再次拍摄 → 点右上角旋转按钮一次。

预期：出现「输出将旋转 90°」提示；点「下一步」后，校正页中的图像方向已旋转 90°（竖版名片变为横版可读）。

## 7. T18 杀进程后数据保持

1. 完成一张名片的保存，并添加一个标签、填写备注。
2. 从多任务界面上滑杀掉 App。
3. 冷启动 App，打开该名片。

预期：姓名/公司/职位/电话/邮箱/地址/标签/备注与原图全部保留；列表顺序按最近更新排列。

## 8. T19 系统分享面板导出 vCard

1. 打开任意名片 → 点「分享」。
2. 在系统分享面板选择「存储到文件」。

预期：面板中文件名为 `.vcf`；保存后用「文件」App 打开，内容以 `BEGIN:VCARD` 开头并含 `FN:` / `TEL;TYPE=CELL:` 等行。

## 8b. T31/T32/T33 存入通讯录（0022）

**T31 成功写入**

1. 打开一张含姓名、公司、职位、手机号的名片 → 点「存入通讯录」。
2. 首次点击时允许通讯录权限。
3. 打开系统「通讯录」App 查看。

预期：按钮变为「已存入」且不可再点；通讯录新增同名联系人，手机号在「手机」标签、办公电话与传真在「工作」标签、邮箱/网址/地址齐全；再次点击不会写入第二条。

**T32 权限拒绝**

1. 系统设置 → BizScan → 通讯录 关闭。
2. 回到 App，打开名片 → 点「存入通讯录」。

预期：弹出「需要通讯录权限」，含「前往设置」；点击后跳转本 App 设置页；App 不崩溃。

**T33 重复联系人**

1. 先在通讯录中新建同名且同号码的联系人。
2. 回到 App，对该名片点「存入通讯录」。

预期：提示「该联系人已在通讯录中」；通讯录仍只有一条。

**T26 外部跳转**

1. 详情页点「电话」快捷按钮或号码本身。
2. 点地址。
3. 点邮箱 / 网址。

预期：分别调起电话、地图、邮件、浏览器并预填对应内容；返回 App 后仍停留在详情页。
