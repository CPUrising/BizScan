# 黑盒观察记录

> 观察对象：`docs/reference-env.md` 锁定的 CamCard 版本。
> 原则：只记录**可观察行为**，不推测内部实现。每条结论必须附截图或录屏索引。

## 1. 页面清单（`pages.md` 摘要）

| 页面 | 入口 | 关键元素 | 可观察状态 | 证据 |
|---|---|---|---|---|
| 名片夹首页 | 启动应用 | 列表、空态、扫描按钮、搜索入口 | 空 / 有数据 / 搜索筛选 | 待补 |
| 相机页 | 名片夹 → 扫描 | 预览、快门、相册、返回 | 权限允许 / 拒绝 / 受限 | 待补 |
| 拍摄结果预览 | 快门后 | 图像、确认、重拍、取消 | — | 待补 |
| 边界校正页 | 确认图像 | 四角控制点、旋转、重拍 | 自动检测成功 / 失败 | 待补 |
| 识别结果页 | 校正确认 | 字段列表、原图对照、保存 | 识别中 / 成功 / 空结果 | 待补 |
| 名片详情页 | 列表点击 | 原图、字段、编辑、删除、导出 | 只读 / 编辑 | 待补 |
| 搜索页 | 首页搜索 | 输入框、结果、清空 | 有结果 / 无结果 | 待补 |

## 2. 状态清单（`states.md` 摘要）

必须逐一确认：

- [ ] 首次启动且无数据
- [ ] 有数据且列表超出一屏
- [ ] 相机权限：未决定 / 允许 / 拒绝 / 受限
- [ ] 相册权限：允许 / 拒绝
- [ ] 拍摄后停留预览、重拍、取消
- [ ] 检测成功、检测失败（无四边形）
- [ ] OCR 无文字、OCR 部分字段
- [ ] 保存中、保存失败（磁盘/权限）
- [ ] 搜索无结果
- [ ] 删除确认与取消
- [ ] 应用被杀死后重启

## 3. 关键流程（`flows.md` 摘要）

对每个流程记录：入口 → 每步动作 → 界面反馈 → 数据变化 → 退出方式。

1. 首次启动到空态
2. 拍摄一张标准名片并保存
3. 相册导入并保存
4. 识别错误后人工校正
5. 搜索与标签筛选
6. 删除名片
7. 导出联系人
8. 任意步骤中途返回/取消

## 4. 异常与系统弹窗（`anomalies.md` 摘要）

- 权限拒绝后的文案与按钮
- 无相机设备 / 模拟器行为
- 相册无权限时的降级路径
- 返回手势与物理返回的差异
- 杀进程后未保存草稿是否保留

## 5. 观察结论模板

对每张测试名片回答：

```
输入：<图片 case id>
CamCard 输出：
  - 是否自动检测到边界：是/否

  - 是否出现虚构字段：是/否（举例）
```
