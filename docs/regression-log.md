## 使用规则

1. **基线只增不改**：历史行不得修改，只追加。
2. `通过用例` 记录 Txx 编号与单测数量，例：`T01,T02,T12 + 24 unit`。
3. 失败用例必须链接到 `docs/verify/<change>.md` 的偏差编号。
4. 归档前若失败数 > 基线，必须说明原因并新开修复 change。
