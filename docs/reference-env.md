## 3. 观察记录规范

每次观察都必须留下可复核证据，放在 `docs/observation/`：

```
docs/observation/
├─ pages.md            # 页面清单：入口、元素、可点击区域
├─ states.md           # 状态清单：空/加载/成功/失败/权限拒绝/中断
├─ flows.md            # 关键流程时序：进入 → 动作 → 结果
├─ anomalies.md        # 异常路径与系统弹窗行为
└─ screenshots/        # 命名：<页面>-<状态>-<序号>.png
```

页面观察必须回答：「CamCard 究竟把一张名片变成了什么？」——输入（照片）、中间产物（校正图、OCR 文本）、输出（结构化记录、持久化字段、导出格式）。

## 4. 与实现环境的差异声明

| 差异 | 影响 | 处理 |
|---|---|---|
| 实现平台为 iOS 模拟器 + 真机混合 | 模拟器无相机，相机相关场景只能真机或注入图片 | UI 测试用注入图片覆盖；真机手测记录在 `docs/verify/` |
| 复刻产品版本与实现时间差 | CamCard 可能已升级 | 以本表锁定版本为准，不跟随升级 |
| 字段识别引擎不同（Apple Vision vs CamCard 自有模型） | 概率性结果不逐字符相同 | 按字段级准确率与人工校正流程验收 |
